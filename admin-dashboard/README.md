# Admin Dashboard - UjianBrowser
Static dashboard untuk melihat device via Firebase RTDB.

## Deploy
Vercel, Root Directory = `admin-dashboard/` (repo publik).

## Fitur
- List devices (Kode, Kode Device, First/Last Seen, Chipset, SDK)
- "Lancen" per device

## Catatan
- Password di `app.js` — `GANTI_PASSWORD_INI`. Ini client-side: bisa dilihat via DevTools. GANTI.
